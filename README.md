# Personal Portfolio Website

This is a simple personal portfolio website made using HTML, CSS, and JavaScript.

It includes sections like About Me, Education, Skills, Projects, Hobbies, and Contact.

### Technologies Used
- HTML
- CSS
- JavaScript

### How to Run
1. Download or clone this repository.
2. Open the `index.html` file in your browser.

Files:
- index.html: the content and sections
- style.css: the layout and colours
- script.js: dark mode, mobile menu and contact form checks


The contact form only checks the information entered and shows a demo message. It does not send emails because this project does not have a backend.
This project was created as a way to practise web development and showcase my work.
